# PCM Map editor

## Rojo part

Generated by [Rojo](https://github.com/rojo-rbx/rojo) 7.7.0.

### Getting Started

To build the place from scratch, use:

```bash
wally install
```

```bash
rojo build -o "PCM Map editor.rbxlx"
```

Next, open `PCM Map editor.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

For more help, check out [the Rojo documentation](https://rojo.space/docs).

## Useful part

### Introduction

This is the map editor made for users of Pretty Cool Mod.
It is made to run inside of Roblox, and to mimic Roblox Studio's behaviour the closest possible.

### Using the editor

#### Controls

You can move the camera using WASD for horizontal movement and QE for vertical.
You can also rotate the camera by moving your mouse while holding right-click.
